# Performance report: `@stellar/stellar-sdk` 17.0.0-rc.2 vs 16.2.0

Generated by `npm run perf` on 2026-08-18 (Node v24.13.0). baseline = `@stellar/stellar-sdk@16.2.0`, candidate = `@stellar/stellar-sdk@17.0.0-rc.2`. Each runs in its own process (no shared JIT/GC/module cache). Single machine, single run — directional, not a controlled lab result.

## Regressions

Single run, so treat these as **provisional** — confirm with repeated runs and check the ± error column before calling them definitive regressions.

- **fromXDR**: -57% slower in the candidate (±0.1%).

## Caveats

- **Signing:** the candidate signs via pure-JS `@noble/ed25519`. These numbers compare against the baseline's pure-JS path. If the baseline had the native `sodium-native` addon installed (the old `FastSigning`), that native path is far faster than either, and the candidate would be a regression against it. Report sign/verify with that asterisk.
- Single machine, single run. For a publishable number, run on an idle/pinned machine and repeat. Treat <±5% as a wash.
