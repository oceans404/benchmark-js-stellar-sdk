# Runtime compatibility report: `@stellar/stellar-sdk` 17.0.0

Generated by `npm run smoke` on 2026-08-21. Each runtime runs the same operations against the candidate (`@stellar/stellar-sdk@17.0.0`), with **no polyfills installed**, so a missing global fails loudly rather than hiding.

Checks run in every runtime:

- keypair: random + sign + verify
- strkey: encode/decode round-trip
- hash: sha256 of bytes
- tx: build + sign + toXDR

## Caveats

- **Scope:** these four checks exercise crypto + XDR primitives only. They do NOT exercise Horizon HTTP, RPC, or SSE streaming. A green row means the core primitives work on that runtime, not that every SDK feature does.
- **"Browser (simulated)" is not a real browser** — it is Node with the `Buffer` global deleted, which tests whether 17.0.0 stands alone without that global. A headless-browser (Playwright) run would be stronger.
- The browser and Cloudflare Workers passes rely on the bundler inlining a `buffer` shim. They run, but this is not yet "zero-dependency, no polyfills."
- Skipped runtimes are not failures — install them to fill in the matrix (`bun`, `deno`, or `npm i -D wrangler`).
