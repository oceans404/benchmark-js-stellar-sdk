# Performance report: `@stellar/stellar-sdk` v16-rc vs v15

Generated by `npm run perf` on 2026-06-09 (Node v24.13.0). v15 = 15.1.0, v16 = 16.0.0-rc.1. Each version runs in its own process (no shared JIT/GC/module cache). Single machine, single run — directional, not a controlled lab result.

## Summary

v16 imports 29% faster (cold, median). Hot paths: 6 faster, 1 slower (>5% threshold). Apparent regressions (single run — confirm before trusting, see ± column): keypair.random -31%.

## Regressions

Single run, so treat these as **provisional** — confirm with repeated runs and check the ± error column before calling them definitive regressions.

- **keypair.random**: -31% slower in v16 (±0.2%).

## Caveats

- **Signing:** v16 signs via pure-JS `@noble/ed25519`. These numbers compare against v15's pure-JS path. If a v15 deployment had the native `sodium-native` addon installed (the old `FastSigning`), that native path is far faster than either, and v16 would be a regression against it. Report sign/verify with that asterisk.
- Single machine, single run. For a publishable number, run on an idle/pinned machine and repeat. Treat <±5% as a wash.
- These are for an RC (`16.0.0-rc.1`); re-run on stable v16.
